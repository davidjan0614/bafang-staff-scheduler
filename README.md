# 8方雲集員工排班程式

手機優先的 PWA 排班工具，可在 iPhone Safari 與 Android Chrome 使用並加入主畫面。

## 線上版本

https://davidjan0614.github.io/bafang-staff-scheduler/

## 目前功能

- Admin 與每位員工使用不同的四位數密碼登入
- 正職／PT 員工新增、編輯、停用與恢復
- 已確認的初始員工與時段
- 正職每月休假目標（預設 8 天）
- PT 不計休假，只管理實際排班日期與時段
- 建議排休、休假進度與最低人力警告
- 員工以手機選擇本人後提出休假申請，Admin 核准後自動寫入班表
- Admin 可逐日手動編輯上班／休假、上下班時間與工作天數
- 正職月休目標；PT 只計實際排班工作日
- 每日最低正職人力警示
- 指定兩人「盡量不同班次」軟性約束；重疊時警示，Admin 填原因後可覆寫
- 所有核准、班別覆寫、員工與設定異動皆保留最近修改紀錄
- 手機月曆與全員整月總表；離線快取與 Supabase 跨手機同步

## 執行

`dist/` 是可直接部署的靜態網站。請用 HTTP 伺服器開啟，避免直接雙擊 HTML；PWA 安裝與離線功能需要 HTTPS 或 localhost。

## 資料與安全限制

目前已接 Supabase。每位員工以獨立四位數密碼登入，資料庫只保存密碼雜湊；員工只能讀取自己的休假申請，並透過受限程序提出新申請，無法修改班表。Admin 可在員工管理中重設個人密碼。

## 後續規劃
