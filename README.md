# 8方雲集員工排班程式

手機優先的 PWA 排班工具，可在 iPhone Safari 與 Android Chrome 使用並加入主畫面。

## 線上版本

https://bafang-staff-scheduler.elatedelm256.chatgpt.site/?v=4

## 第一版功能

- Admin 測試登入（密碼 `8888`）與員工唯讀模式
- 正職／PT 員工新增、編輯、停用與恢復
- 已確認的初始員工與時段
- 正職每月休假目標（預設 8 天）
- PT 不計休假，只管理實際排班日期與時段
- 建議排休、休假進度與最低人力警告
- 手機月曆與每日上班／休假切換
- 正職整月總表：姓名對照 1～31 日，可直接查看及修改休假
- 瀏覽器本機資料保存及離線快取

## 執行

`dist/` 是可直接部署的靜態網站。請用 HTTP 伺服器開啟，避免直接雙擊 HTML；PWA 安裝與離線功能需要 HTTPS 或 localhost。

## 資料與安全限制

此版本是可操作原型，資料只保存在目前瀏覽器。測試密碼不是正式安全機制。正式多人版本應接 Supabase 或 Firebase，加入真正的管理員登入、資料庫權限、備份及跨手機同步。

## 後續規劃

1. 確認每日早／午／晚最低人力。
2. 加入員工希望休假與不可上班日。
3. 接上雲端帳號與資料庫。
4. 加入班表發布、員工確認及異動紀錄。
5. 將原始碼同步至使用者指定的 GitHub repository。
